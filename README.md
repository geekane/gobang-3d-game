# 五子棋 AI 对战 · Gobang AI Game

15×15 经典五子棋人机对战小游戏，开箱即用。

## 功能

- 🎮 人机对战 AI（启发式评分 + 2 步预判）
- 🎚️ 三档难度：新手 / 进阶 / 大师
- ♟️ 执黑先行 / 执白后行 / 交换先后手
- ↩️ 悔棋（同时撤回你与 AI 各一步）
- 🔄 重新开始
- 🏆 胜负判定（横 / 竖 / 斜五连 + 和棋）
- 💡 AI 支招（提示最佳落子）
- 📜 棋谱记录 + 手数统计 + 最后一手标记
- ✨ 玻璃拟态 + 渐变深色 UI，响应式适配手机/桌面

## 运行

直接用浏览器打开 `index.html` 即可，无需构建：

```bash
# 方式一：双击 index.html
# 方式二：本地服务（推荐）
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 文件结构

```
index.html  页面结构
style.css   样式（深色玻璃拟态）
script.js   棋盘绘制 / 规则判定 / AI 算法 / 交互
```

## AI 算法说明

- 对距离棋子 2 格内的所有空位生成候选。
- `evalPoint` 按四方向统计连子数与开口数打分：
  五连 1,000,000 / 活四 100,000 / 冲四 10,000 / 活三 5,000 / …
- 每步分数 = 进攻分 × 1.0 + 防守分 × 0.9，立即成五 / 必须堵四额外加权。
- 大师难度对 Top8 候选做 1 层回应预判（2-ply）：`value = myScore - oppBest × 0.85`。
