# 3D 沉浸式五子棋 · 3D Gobang Experience

Three.js 打造的 3D 沉浸式五子棋：实木 / 黑曜石棋盘、墨玉与白玉棋子、电影级光影、自由视角、华丽胜负粒子特效，开箱即用。

## 功能

- **3D 场景**：15×15 金丝网格棋盘、倒角立体底座、5 星位标记
- **3D 棋子**：双凸扁球体，黑子墨玉微反光 / 白子白玉温润质感（MeshPhysicalMaterial）
- **电影级光影**：环境光 + 阴影方向主光 + 冷暖双点光源 + ACES 色调映射
- **自由视角**：OrbitControls 旋转 / 平移 / 缩放，一键重置俯视、顶视切换、自动旋转
- **3D 拾取**：Raycaster 悬停半透明预览棋，点击从空中轻落 + 回弹 + 音波涟漪光环
- **最后一手**：悬浮发光金色光环指示器（旋转 + 呼吸脉冲）
- **胜利特效**：金色贯通能量光柱 + 五子节点光柱 + 金光粒子礼花雨 + 摄像机缓动特写
- **落败特效**：幽蓝/深红粒子 + 冷色冲击波闪屏 + 镜头震颤 + 棋盘抖动
- **和棋特效**：黑白太极双色粒子回旋交织 + 磨砂玻璃面板
- **核心玩法（完整保留）**：启发式 AI（新手 / 进阶 / 大师 2-ply 预判）、悔棋（棋子浮起消散）、重开、黑白先后手切换、AI 思考呼吸光效、棋谱记录

## 3D 操作说明

| 操作 | 说明 |
| --- | --- |
| 左键点击交叉点 | 落子 |
| 左键拖拽 | 旋转视角 |
| 右键拖拽 | 平移视角 |
| 滚轮 | 缩放 |
| `R` / 重置视角按钮 | 回到默认俯视角度 |
| `T` / 顶视按钮 | 切换正顶视 |
| `空格` / 自动旋转按钮 | 开关场景自动旋转 |

窗口缩放时摄像机比例与渲染器尺寸自适应。

## 运行

需要联网加载 Three.js CDN（unpkg），直接用浏览器打开 `index.html` 即可，无需构建：

```bash
# 推荐：本地服务
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> CDN（importmap）：`https://unpkg.com/three@0.160.0/build/three.module.js`
> 与 `https://unpkg.com/three@0.160.0/examples/jsm/controls/OrbitControls.js`

## 校验

```bash
node --check script.js
```


## AI 算法说明

- 对距离棋子 2 格内的所有空位生成候选。
- `evalPoint` 按四方向统计连子数与开口数打分：
  五连 1,000,000 / 活四 100,000 / 冲四 10,000 / 活三 5,000 / …
- 每步分数 = 进攻分 × 1.0 + 防守分 × 0.9，立即成五 / 必须堵四额外加权。
- 大师难度对 Top8 候选做 1 层回应预判（2-ply）：`value = myScore - oppBest × 0.85`。
